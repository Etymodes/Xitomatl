# 时茄 Xitomatl

时茄是一款 Windows 桌面应用，将任务登记、随机抽取和专注计时串成一条简单的流程：写下待办，抽取或自选一件事，专注后记录结果，再查看每日总结。

## 首版功能

- 登记每日、每周、限期、单次和长期计划任务。长期计划默认不进入抽取池，可手动移入待办。
- 为每项任务添加 SOP 步骤，逐项勾选、取消勾选；已完成步骤显示删除线。每日和每周任务可以单独标记“完成本轮”。
- 在扭蛋桶与转盘之间切换抽取外观。临近截止日期和久未触达的任务获得有限的额外权重；结果会解释抽取原因，也允许重抽或直接选任务。
- 使用不定时、15 分钟、25 分钟、45 分钟或自定义时长专注。计时可暂停与恢复；短暂刷新可接续，应用长时间未运行时会自动暂停，避免把离线时间计入专注。倒计时结束可选择全屏覆盖、响铃或同时启用。
- 通过“任务归档”“结束本次”“结束当日”记录不同结果，生成可复制的每日总结。
- 提供暖番茄、森林绿和墨色主题，以及 JSON 备份导入、导出。

## 在 Windows 上运行

如已取得 `Xitomatl-0.1.0-win-x64-portable.exe`，双击即可运行，无需安装。首次启动可能需要等待数秒。应用数据保存在本机当前用户的时茄应用存储中，建议定期从“设置”导出 JSON 备份。

从源码运行需要 Node.js 24 或兼容版本：

```powershell
npm install
npm run desktop:start
```

开发时可用 `npm run desktop:dev` 启动桌面窗口及前端热更新。仅预览网页界面可运行 `npm run dev`。构建 Windows 便携版和运行测试：

```powershell
npm run desktop:package:win
npm test
```

便携版输出到 `release/`。构建需要下载 Electron 与打包工具；已有依赖时，应用本身无需联网即可使用。

## 数据与设计边界

首版没有账户或云端同步。清除应用数据或切换用户账户会影响本机记录；迁移设备请使用 JSON 备份。损坏的数据会先保留原始内容，多窗口中发现较新的本地数据时会停止旧窗口写入。

抽取权重与建议时长是可解释的产品规则，不是对个人效率的科学预测。25 分钟只是初始建议，用户可以随时调整。详见[资料调研](docs/research.md)。

## 代码结构

- `src/core/`：任务周期、抽取、时长建议、会话与每日总结。
- `src/timer.ts`：可恢复的正计时和倒计时。
- `src/storage.ts`：本地数据、备份及写入冲突保护。
- `src/App.tsx`、`src/styles.css`：应用界面与交互。
- `electron/`：Windows 桌面窗口、应用协议和提醒全屏控制。

后续开发重点将根据真实使用反馈调整任务筛选、阶段计划与自适应规则。
